<h1 align="center">📇 ContactMate – Contact Management Web Application</h1>
<h3 align="center">Spring Boot | Thymeleaf | Spring Security | JPA | MySQL</h3>

<p align="center">
ContactMate is a secure, full-stack contact management web application that allows users to manage their personal and professional contacts efficiently. It is built using Spring Boot and Thymeleaf, following clean MVC architecture and real-world backend development practices.
</p>

---

## 🚀 Key Features

- 🔐 Secure authentication & authorization (Spring Security)
- 👤 User registration & login system
- 📇 Add, update, view & delete contacts (CRUD)
- 🖼 Profile image upload for contacts
- 🔍 Search & filter contacts
- 📄 Pagination support
- ✏️ User profile management
- ⚠️ Server-side validation & centralized exception handling
- 🧩 Clean layered architecture (Controller → Service → Repository)
- 🌐 Thymeleaf-based dynamic UI
- 🛢 MySQL database integration
